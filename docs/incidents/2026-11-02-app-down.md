## Nguyên nhân

Nginx trả về lỗi 502 khi không thể kết nối đến backend.

- Kiểm tra trạng thái container bằng docker compose ps.

- Khởi động lại app bằng docker compose start app.
- Kiểm tra cảnh báo Discord chuyển sang trạng thái RESOLVED.
